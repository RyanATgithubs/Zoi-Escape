ABOUT THE DEVELOPER

This project was developed as a web-based game platform that integrates Unity WebGL, HTML, CSS, JavaScript, and Google Authentication. The website serves as a testing hub for the game’s demo level, featuring leaderboard tracking, responsive design, and interactive gameplay testing. Users can explore the development process, learn about the tools and technologies used, and access links to the project repository.

The game was developed and exhibited in 2025 by 2nd-year students of the Bachelor of Science in Entertainment and Multimedia Computing (BSEMC) program at the University of Caloocan City. This project demonstrates collaborative student efforts in game design, programming, and web integration, showcasing both technical skills and creativity.
